# Speedo Bus Route Finder

Speedo Bus Route Finder is a web application that helps users find the best bus routes based on their starting point and destination. The app is built using HTML, CSS, and JavaScript.

## Features

- **Dynamic Dropdowns**: Automatically populated dropdowns for selecting start and destination points.
- **Route Finder**: Finds and displays all possible routes between the selected start and destination points.
- **User-Friendly Interface**: Simple and clean UI for easy navigation.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Styling**: Custom CSS for responsive and interactive design.
